# Этап 1 — модульное ядро транзакций

## Реализовано

- отдельный каталог `backend/v2` вместо добавления логики в legacy-монолит;
- реестр ETH, BNB, TRON и BTC;
- проверка формата адреса и честное обозначение неоднозначности EVM-адресов;
- адаптеры EVM, TRON и Bitcoin с единым интерфейсом;
- единая схема транзакции v2;
- токеновые операции ERC20/TRC20;
- полные Bitcoin inputs/outputs;
- live/cursor/page пагинация;
- сохранение raw provider response с SHA-256;
- обязательная авторизация для истории и live detection;
- контрактные тесты на детерминированных provider fixtures;
- frontend-сервис для постепенного подключения UI к v2.

## Не подменяется догадками

- одинаковый 0x-адрес может существовать в нескольких EVM-сетях;
- Bitcoin change output не назначается владельцу автоматически;
- частичный ответ провайдера помечается как partial;
- отсутствие транзакций на первой странице не означает отсутствие адреса или владельца;
- blockchain-адрес не связывается с физическим лицом без внешнего подтверждения.
