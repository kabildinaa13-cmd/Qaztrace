План

ChainSentra будет разрабатываться как web-платформа для анализа криптокошельков, отслеживания транзакций и построения расследований по on-chain активностям.

На первом этапе будет реализован MVP:
- поиск и определение сети по адресу кошелька;
- карточка кошелька с балансом, количеством транзакций и базовой активностью;
- история транзакций;
- граф связей между адресами;
- watchlist для отслеживания адресов;
- Telegram-уведомления по событиям;
- сохранение кейсов расследований;
- ручная база entity labels для бирж, миксеров, bridges и подозрительных адресов.

На следующем этапе система будет расширена внешними data providers:
- Arkham для обогащения адресов entity intelligence;
- RouteScan для multichain EVM-истории и explorer-данных;
- дополнительные провайдеры для сетей, где стандартного RPC недостаточно.

Архитектура

Архитектура будет состоять из трех основных слоев:

1. Frontend
- web-интерфейс для аналитика;
- поиск адресов;
- профили кошельков;
- граф транзакций;
- watchlist;
- алерты;
- панель расследований.

2. Backend API
- единая точка доступа для frontend;
- нормализация данных от разных blockchain providers;
- работа с профилями кошельков, кейсами, labels и watchlist;
- расчет risk-score и suspicious routes;
- отправка Telegram-уведомлений.

3. Data Layer
- на MVP-этапе можно использовать JSON/local storage;
- далее будет подключена полноценная база данных;
- отдельно будут храниться кошельки, транзакции, связи, labels, кейсы и события мониторинга.

Стэк

Планируемый стек:
- React для frontend;
- Vite для сборки;
- Tailwind CSS для интерфейса;
- Node.js для backend API;
- REST API между frontend и backend;
- PostgreSQL или другая БД на следующем этапе;
- Telegram Bot API для уведомлений;
- внешние blockchain/data APIs для получения on-chain данных.

API, которые будут использоваться

На старте планируется подключить:

1. Infura / MetaMask Developer API
Для EVM-сетей: баланс, transaction count, latest block, базовые RPC-запросы.

2. TronGrid API
Для TRON: баланс, аккаунт, история транзакций, блоки.

3. Etherscan API v2
Для indexed history по EVM-адресам, так как обычный JSON-RPC не дает полноценный список транзакций по адресу.

4. Telegram Bot API
Для отправки уведомлений по watchlist-событиям.

Далее будут подключаться:

1. Arkham API
Для entity intelligence: labels, tags, связи адресов с организациями, биржами, фондами, миксерами и другими известными сущностями.

2. RouteScan API
Для multichain EVM explorer-данных: история транзакций, token transfers, contract metadata и поддержка сетей, где нужны дополнительные indexed данные.

Итоговая идея

ChainSentra будет не просто обозревателем кошельков, а инструментом расследований: он будет собирать данные из разных источников, нормализовать их, показывать связи между адресами, находить подозрительные маршруты движения средств и уведомлять пользователя о новых событиях.
