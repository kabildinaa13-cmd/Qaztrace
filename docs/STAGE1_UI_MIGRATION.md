# Этап 1.2 — экран транзакций на API v2

## Изменения

- основной экран истории ETH, BNB, TRON и Bitcoin получает данные через `/api/v2`;
- режим `All EVM` независимо проверяет Ethereum и BNB Smart Chain;
- нормализованные v2-операции адаптируются к текущей таблице без потери исходной структуры;
- существующий explainable risk-анализ выполняется поверх v2-операций;
- по нажатию на hash открывается доказательная карточка;
- карточка показывает сеть, сумму, блок, время, статус, все адреса, источник, время получения, raw response ID и SHA-256;
- для Bitcoin показываются все inputs и outputs и явное ограничение по change-address;
- ссылка на внешний explorer отделена от открытия внутренней карточки.

## Что намеренно не изменено

Граф и его lazy-loading пока используют legacy endpoint. Переключение графа будет отдельным этапом после появления v2 graph builder, чтобы не смешивать нормализованные UTXO-операции с legacy-моделью одного `from/to`.
